# options/

The extension's options page (opened from `chrome://extensions` → **Details → Extension options**).

| File | Purpose |
|---|---|
| `options.html` | Page layout: highlights, on-device model, team sync, release chip |
| `options.css` | Page styles |
| `options.js` | Loads and saves settings, shows model status, tests the team-sync connection, respects policy locks |
